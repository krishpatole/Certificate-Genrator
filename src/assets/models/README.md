# 3D Car Model Placement

Place your realistic 3D car `.glb` file here or in `public/models/`:

### Recommended file paths:
1. `public/models/car.glb` (Recommended for direct browser streaming via Vite)
2. `src/assets/models/car.glb`

### Supported format:
- Standard binary `.glb` or `.gltf` sports car / supercar model.
- The VeloX engine automatically scans mesh names and binds PBR automotive paint, physical tinted glass, wheel rims, tires, brake calipers, and headlights.
